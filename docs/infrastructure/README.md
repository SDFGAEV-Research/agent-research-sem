# Infrastructure Documents

This directory owns reusable platform systems consumed by many projects. Each
subdirectory corresponds to a bounded infrastructure system and documents its
public contracts, lifecycle and operational ownership.

- [`ai/`](ai/README.md) — model assets, serving, prompts and runtime asset
  management.
- [`runtime/`](runtime/README.md) — lifecycle, operator, service, release and
  endpoint control.
- [`server/`](server/README.md) — multi-server identities, connections,
  capacity and persistent sessions.
- [`observability/`](observability/README.md) — logs, telemetry and I/O
  performance.
- [`minecraft/`](minecraft/README.md) — reusable Minecraft environment
  infrastructure.
